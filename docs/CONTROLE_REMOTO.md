# Controle remoto

Tudo funciona só com D-pad, OK e Voltar. Teclas extras (CH±, mídia, números, Menu) são atalhos opcionais.

## Grade (Ao Vivo)
| Tecla | Ação |
|---|---|
| D-pad | move o foco entre os quadrados |
| OK | abre o quadrado em tela cheia (com PTZ) |
| OK segurado (0,6 s) ou Menu | menu do quadrado: tela cheia, gravações, reconectar, qualidade, modo de lente, ocultar |
| ← na coluna esquerda | abre o menu lateral (Ao Vivo, Gravações, Configurações, Diagnóstico, Sobre) |
| CH+/CH− | troca a página da grade (ou o layout, se só houver uma página) |
| Mídia próxima/anterior | alterna o layout |
| Voltar | fecha o menu; senão, "Pressione Voltar novamente para sair" |

## Tela cheia
| Tecla | Ação |
|---|---|
| Setas (seguradas) | movem a câmera; soltar para. Duas setas = diagonal |
| OK ou Menu | mostra a barra de controles (some em 5 s) |
| Setas com zoom ativo | movem a área ampliada |
| Setas sem PTZ | ←/→ trocam de câmera |
| 1–9 | vai para o preset (se a câmera tiver) |
| CH+/CH−, mídia | próxima/anterior câmera |
| Voltar | fecha a barra; de novo, volta para a grade |

Barra de controles: Foto · Gravar na TV Box · Áudio · Presets · Zoom + / − · Lente · Inverter controles · Velocidade · Gravações · Informações.

## Gravações
| Tecla | Ação |
|---|---|
| ←/→ na linha do tempo | move o cursor (segurar acelera: 1 min → 10 min → 1 h) |
| OK | reproduz a partir do cursor |
| OK (no player) | pausa / continua |
| ←/→ (no player) | −10 s / +10 s (segurar: 60 s) |
| ↑/↓ (no player) | velocidade 0,5x · 1x · 2x · 4x |
| Voltar | sai |
