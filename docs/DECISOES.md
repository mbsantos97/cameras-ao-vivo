# Decisões

Registro das escolhas feitas durante o desenvolvimento (data, decisão, motivo). Mais recentes no fim.

| Data | Decisão | Motivo |
|---|---|---|
| 21/11/2026 | Versões: AGP 9.5.2, Gradle 9.9.2, Kotlin 2.4.21, Compose BOM 2026.11.01, tv-material 1.1.0, LibVLC 3.7.7, OkHttp 5.5.1 (todas consultadas no Maven na data). | Regra 6: estáveis mais recentes, fixadas em `gradle/libs.versions.toml`. |
| 21/11/2026 | `compileSdk` 37.2 (`release(37) { minorApiLevel = 2 }`), `targetSdk` 37, `minSdk` 24. | As bibliotecas do Compose 1.13 exigem compilar contra 37.1 ou superior. |
| 21/11/2026 | Kotlin embutido do AGP 9 (sem aplicar `org.jetbrains.kotlin.android`); o plugin é só declarado na raiz para fixar o Kotlin 2.4.21. | O AGP 9 traz suporte a Kotlin próprio; aplicar o plugin antigo conflita. |
| 21/11/2026 | ktlint pela CLI oficial (`com.pinterest.ktlint:ktlint-cli`) em tasks `ktlintCheck`/`ktlintFormat`, em vez do plugin Gradle de terceiros. | O plugin não é garantido com o Kotlin embutido do AGP 9; a CLI não depende disso. |
| 21/11/2026 | Bibliotecas nativas comprimidas no APK (`useLegacyPackaging = true`) e sem `lib/x86/**`; `x86_64` sai do pacote no release. | Sem compressão o APK arm64 passava de 70 MB; com compressão fica em ~25 MB (meta ≤ 35 MB). Nenhuma TV Box alvo é x86. |
| 21/11/2026 | APK release sem keystore (ex.: PR) é assinado com a chave de debug, só para teste. | Permite testar o release com R8 sem segredos; a Release oficial usa o keystore dos secrets. |
| 21/11/2026 | Menu lateral próprio (componente `DrawerItem` do DS), não o `NavigationDrawer` do tv-material. | O drawer do tv-material deixa uma faixa recolhida sempre visível; o requisito é o vídeo usar a tela inteira e o menu abrir só com ← na coluna esquerda. |
| 21/11/2026 | Foco e clique próprios (`aoVivoFocus`/`aoVivoClickable`) em vez do `Surface` clicável do tv-material. | Controle exato dos tokens (anel de 3 dp + contorno interno, escala 1.04 em 120 ms), sem ripple, e toque curto × longo com a máquina de estados testada. |
| 21/11/2026 | Texto `danger` não é usado sobre `surfaceRaised`/`surfaceHigh`: botão perigoso = fundo `danger` com texto preto (5,9:1); linha perigosa = ícone `danger` e texto `textPrimary`; etiquetas sobre `danger` com texto preto. | O teste de contraste mostrou 4,44:1 para `danger` sobre `surfaceRaised` (mínimo 4,5:1). Os valores dos tokens da especificação foram mantidos. |
| 21/11/2026 | Borda de movimento estática (3 dp `danger`) + etiqueta "Movimento" por 10 s, sem pulsar. | O DS permite só duas animações contínuas (conectando e REC). |
| 21/11/2026 | Relógio sobreposto na margem superior da área segura, fora da grade. | No canto superior direito ele cobria as etiquetas do quadrante (visto no print gerado). |
| 21/11/2026 | Sem `java.time` (minSdk 24): datas com `SimpleDateFormat` em `ThreadLocal` (`core/time/Formats`). | Evita core library desugaring (peso e tempo de build). |
| 21/11/2026 | Prints das telas gerados pela JVM (Robolectric em modo gráfico nativo + `captureToImage`), em `docs/screens`. | O emulador não roda nesta máquina (Windows Hypervisor Platform desligado; ligar exige admin e reinício). O vídeo (TextureView) não renderiza pela JVM; nos prints os quadrantes usam fundo simulado. |
| 21/11/2026 | Sem cabos: instalação e atualização só por adb pela rede (`adb connect`/`adb pair`), nunca USB; no assistente, "Configurar pelo celular" é a opção em destaque (botão primário e foco inicial). | Requisito "Sem cabos": a TV Box fica longe do PC. |
| 21/11/2026 | ONVIF com SOAP escrito à mão + `XmlPullParser` montando uma árvore com nomes sem prefixo (`XmlTree`); parsers casam pelo local name, sem diferenciar maiúsculas. | Tolerância a respostas SOAP fora do padrão; zero bibliotecas ONVIF. |
| 21/11/2026 | Autenticação ONVIF em cascata: WS-Security (relógio corrigido por `GetSystemDateAndTime`) → HTTP Digest em 401 → sem autenticação se a câmera aceitar. SOAP 1.1 em 400/415 sem Fault. | Quirks de firmware Yoosee; cada câmera aceita uma combinação diferente. |
| 21/11/2026 | XAddrs reescritos para o host e a porta ONVIF configurados; URIs RTSP para o host e a porta RTSP configurados. | Firmware devolve 0.0.0.0, IP antigo ou porta 80. |
| 21/11/2026 | Fault "ação não suportada" reconhecido por qualquer subcódigo aninhado e por "Not Implemented". | Achado nos testes com a fixture de Fault (subcódigos `ActionNotSupported/NoRecording`). |
| 21/11/2026 | Testes do ONVIF com MockWebServer simulando a câmera inteira; integração opcional contra o mock (`-PmockCamera=IP:porta`). | Validar sem câmera real; o vetor do WS-Security foi conferido com openssl. |
| 21/11/2026 | Base64 via okio (já vem com o OkHttp) e `ThreadLocal` por subclasse. | `java.util.Base64` e `ThreadLocal.withInitial` exigem API 26 (minSdk 24). |
| 21/11/2026 | Recorte e zoom: o LibVLC estica o quadro para a view inteira (`setAspectRatio("W:H")` + `setScale(0)`) e a matriz do `TextureView` desfaz a distorção e recorta (`VideoTransform`). | Um único decodificador serve coluna dupla, só cima/baixo, compacto e zoom digital, sem refazer o player. |
| 21/11/2026 | Primeiro frame e watchdog pelas estatísticas do LibVLC (`Media.getStats().displayedPictures`, lidas a cada 1 s). | Não depende de sobrescrever o `SurfaceTextureListener` que o LibVLC usa internamente. |
| 21/11/2026 | Sem vídeo em 6 s: com dados chegando → decodificação por software (lembrada na câmera); sem dados no modo Auto → TCP (lembrado). | O fallback interno do LibVLC para TCP só ocorre após 10 s; assim cada causa recebe o remédio certo. |
| 21/11/2026 | A grade só abre sessões para as fontes da página visível, até 4 (`DecoderBudget.maxStreams`); em tela cheia, só a fonte aberta. | Limite de instâncias de decodificador de hardware dos SoCs Amlogic. |
| 21/11/2026 | Após 3 falhas seguidas os streams são resolvidos de novo; após 5, a câmera é procurada na rede pelo serial/MAC (IP trocado por DHCP). | Requisito 7.2 sem custo quando a câmera está estável. |
| 21/11/2026 | Lente empilhada também detectada em tempo de execução pelo tamanho de vídeo reportado pelo player (modo Auto). | Algumas câmeras não informam a resolução real no ONVIF. |
| 21/11/2026 | PTZ numa fila serial por câmera (`Channel`): Start e Stop sempre em ordem; ContinuousMove com `Timeout PT10S`; watchdog de 8 s; Stop ao perder o foco. Modo Passo tenta RelativeMove e, se a câmera recusar, usa ContinuousMove `PT0.4S` + Stop. | Requisito 7.3; evita câmera girando sozinha se um KeyUp se perder. |
| 21/11/2026 | "Inverter controles" na barra inverte os dois eixos de uma vez; os eixos separados ficam na edição da câmera. | Caso típico: lâmpada instalada de cabeça para baixo inverte os dois. |
| 21/11/2026 | Detecção automática de "câmera ignora Stop" não implementada; o modo Passo fica disponível na edição da câmera. | Detectar exige ler o MoveStatus do GetStatus, que câmeras baratas nem sempre informam; sem câmera real não dá para validar. |
| 21/11/2026 | Fotos em `Android/data/<app>/files/Pictures` (área do app, sem permissão). | Requisito de não pedir permissões de armazenamento. |
| 21/11/2026 | Gravação na TV Box por remux do LibVLC (`:sout=#std{access=file,mux=ts,dst=…}`), uma sessão por câmera separada da exibição, segmentos de 10 min reiniciando o MediaPlayer. | Sem decodificar (CPU baixa); MPEG-TS resiste a queda de energia. Entre segmentos há um intervalo de 1–2 s (registrado em LIMITACOES). |
| 21/11/2026 | Serviço de gravação ligado/desligado por um observador da configuração no escopo do app (não bloqueia a abertura). Tipo `specialUse` com `PROPERTY_SPECIAL_USE_FGS_SUBTYPE`. | Requisito 8.2 e Android 14+. Sem `POST_NOTIFICATIONS` (fora da lista de permissões): a notificação pode ficar oculta no Android 13+, mas o serviço roda. |
| 21/11/2026 | Replay do cartão SD: o LibVLC não envia `Range: clock=` nem `Require: onvif-replay`; abrimos o URI de replay e posicionamos com `:start-time`. Se a câmera não aceitar, a tela informa e o caso fica em LIMITACOES. | Proibido escrever cliente RTP próprio (seção 8.1). |
| 21/11/2026 | Quirks das câmeras reais tratados no `OnvifClient`: XAddr deslocado → `device_service`; relógio autenticado quando o pedido sem autenticação derruba a conexão; `Connection: close`; `Stop` recusado → `ContinuousMove(0,0)`; OkHttp com `retryOnConnectionFailure(true)`. | Medido nas duas câmeras da casa (detalhes em LIMITACOES). |
| 21/11/2026 | Fixtures reais (`real_*.xml`) com senha, serial, MAC e IPs substituídos. | Regra 5: nada de IP real ou serial no repositório. |
| 21/11/2026 | `android.injected.enableStableIds=false` e, se o AAPT2 ainda falhar em `stableIds.txt`, `./gradlew --stop` + apagar `processed_res`. | Falha intermitente de arquivo no Windows. |
| 21/11/2026 | Varredura da rede com 800 ms por porta (era 300 ms). | As câmeras reais demoram a aceitar conexão na porta 5000: com 300–400 ms a busca perdia uma delas. |
| 21/11/2026 | Bibliotecas nativas sem compressão (`useLegacyPackaging = false`): APK armeabi-v7a ~41 MB, mas instalado ocupa ~42 MB em vez de ~61 MB e instala/abre mais rápido. Meta de APK ≤ 35 MB não atingida, conscientemente. | A TV Box real tem 4,3 GB e estava com 91 MB livres: o espaço ocupado importa mais que o tamanho do download. |
| 21/11/2026 | Primeiro quadro = evento `Vout` do LibVLC ou quadros decodificados > 0 (não só "exibidos"); tempo para o primeiro quadro 12 s; no Auto, TCP sem dados volta para UDP. | Na TV Box real (Amlogic, H.265 via MediaCodec direto na superfície) o contador de exibidos não subia e o app reiniciava a cada 6 s; as câmeras só mandam VPS/SPS/PPS no quadro-chave. |
| 21/11/2026 | Lente dupla em "Coluna dupla" desenhada como dois quadrados (faixa de 8 dp com cantos arredondados por cima do vídeo), nomes "Fixa"/"Móvel" conforme a lente motorizada. | Três quadrados distintos; mantém um único decodificador (2 GB de RAM). |
| 21/11/2026 | "Ponto de guarda"/retorno automático e rastreamento ficam no app Yoosee (firmware da câmera). | As câmeras não implementam GetNodes, presets nem Home no ONVIF (conexão derrubada); só ContinuousMove. |
| 21/11/2026 | Sem Baseline Profile próprio: o APK leva `profileinstaller` e os perfis das bibliotecas (Compose). | Gerar o perfil exige root ou Android 13+; a TV Box é Android 11 sem root e não há emulador nesta máquina. Cold start medido 657–935 ms, dentro da meta mesmo assim. |
| 21/11/2026 | 4,2% de quadros acima de 32 ms na navegação, acima da meta de 1%; registrado em `docs/PERFORMANCE.md` em vez de remover a escala do foco. | Os quadros lentos vêm da animação de escala do foco sobre o TextureView. Mitigação proposta: escalar só o anel/rótulos. Não afeta o vídeo nem os controles. |
| 21/11/2026 | IPs de exemplo nos textos e na documentação: 192.168.1.50 (câmera) e 192.168.1.20 (TV Box). | Não deixar os IPs reais da instalação no repositório. |
